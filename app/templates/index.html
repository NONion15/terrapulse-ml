Section 1

Project Overview

This project implements a machine learning system for estimating residential real estate values. The primary focus is the Ames, Iowa housing dataset, with an additional high-volume international dataset used to evaluate model scalability across global markets.

Rather than using fixed pricing heuristics, the system uses supervised regression pipelines that learn non-linear relationships between property characteristics and historical transaction prices.

Ames Housing Dataset (Primary Focus)

1,460 residential properties with 81 attributes detailing structural characteristics, materials, basement finishes, garage types, and neighborhood locations.

Champion Model: CatBoost (Holdout R-squared: 0.9094)
Global Housing Dataset (Scalability Test)

200,000 transaction records across 13 countries and 40 international metropolitan markets.

Champion Model: Random Forest (Holdout R-squared: 0.9999)
Section 2

Algorithms Evaluated

To determine the most effective approach for tabular real estate data, five regression algorithms were benchmarked under identical cross-validation conditions:

1. Ridge Regression (Linear Baseline)

Ridge regression fits a linear relationship between features and target prices with L2 regularization to prevent extreme coefficient weights. It provides a clean baseline to assess whether non-linear tree ensembles provide meaningful accuracy improvements.

2. Random Forest (Bagging Ensemble)

Random Forest builds an ensemble of decorrelated decision trees, averaging their predictions to reduce variance. On large, uniform datasets like the 200,000-row global dataset, it delivered the highest stability and lowest error rate.

3. LightGBM (Histogram-Based Boosting)

LightGBM grows trees leaf-wise and buckets continuous features into discrete histogram bins, significantly reducing memory consumption and accelerating training speeds on large datasets.

4. XGBoost (Exact Gradient Boosting)

XGBoost builds trees sequentially using second-order gradients and explicit tree-pruning penalties, making it robust against overfitting in tabular competitions.

5. CatBoost (Ames Champion)

CatBoost handles categorical variables through ordered target statistics without causing target leakage during training. Because the Ames dataset contains numerous high-cardinality nominal features (such as 25 distinct neighborhoods and multiple zoning classifications), CatBoost achieved the lowest prediction error of all evaluated models.

Section 4

Feature Engineering

To improve predictive accuracy without overfitting, domain-specific feature transformations were created:

Total Enclosed Footprint

Combines above-grade living area and finished basement area to capture total usable enclosed square footage.

Quality and Condition Interaction

Multiplies Overall Quality by Overall Condition to capture the non-linear relationship between construction grade and ongoing maintenance.

Fractional Bathroom Metric

Computes full bathrooms plus half the count of half-bathrooms to accurately represent sanitary capacity.

Remodel Indicator

Flags whether a property underwent major remodeling after its original construction year.

Section 5

Target Leakage Prevention

During initial analysis of the global dataset, correlation metrics indicated that loan amounts (r = 0.938) and down payments (r = 0.851) were strongly correlated with property prices.

Rationale: In real estate transactions, loan amounts and down payments are computed after property appraisal, not before. Including financing numbers in a valuation model constitutes target leakage.

In the production model, all financing fields were removed. The model trains strictly on intrinsic physical attributes: square footage, room counts, building age, location, and structural characteristics.

Section 6

Valuation Methodology

When evaluating a property, the system follows a structured estimation procedure:

  1. 1. Neighborhood Baseline: Determines the median historical sales price for the specific neighborhood.
  2. 2. Feature Adjustments: Calculates additions and deductions for living area, material quality rating, vintage, and garage storage.
  3. 3. Non-Linear Interaction: CatBoost evaluates interaction terms across all 81 structural attributes.
  4. 4. Confidence Range: Computes a 95% confidence interval based on cross-validation residuals.
